# Xerama Microdrama Story Formula

This document defines the initial storytelling hypotheses Xerama will use. These are starting rules to benchmark and improve, not permanent creative laws.

## 1. Episode Loop

```text
Hook → Context / Stakes → Conflict → Escalation → Turn / Reveal → Cliffhanger
```

For a short vertical episode, the opening must create immediate curiosity or emotion. The ending should normally stop at the point where the viewer most wants the scene or revelation to continue.

## 2. Emotional Engine

A strong serial premise should contain some combination of:

```text
Desire + Obstacle + Injustice + Secret + Reversal + Payoff
```

The system should identify these explicitly before generating large episode counts.

## 3. Information Gap

Xerama should track four information states:

1. Known to the audience.
2. Known to the protagonist.
3. Known to the antagonist or other characters.
4. Hidden from everyone/audience until a planned reveal.

This enables dramatic irony, mysteries, betrayals, misunderstandings, and controlled reveals.

## 4. Serial Progression

A season should not be a collection of disconnected cliffhangers. It should operate as a reveal and escalation ladder:

```text
Question
  ↓
Partial Answer
  ↓
New Problem
  ↓
Reversal
  ↓
Bigger Question
  ↓
Escalation
  ↓
Payoff
```

## 5. Cliffhanger Types

Xerama should classify and rotate cliffhangers to reduce repetition:

- identity reveal
- unexpected arrival
- betrayal
- discovery
- threat
- power reversal
- interrupted confession
- physical danger
- exposed secret
- impossible choice
- false victory
- new mystery
- relationship reversal
- evidence reveal
- countdown/deadline

## 6. Candidate Scoring

Initial story scoring dimensions:

| Dimension | Purpose |
| --- | --- |
| Hook | Immediate attention potential |
| Premise clarity | Can the audience understand the dramatic situation quickly? |
| Emotional intensity | Strength of emotional investment |
| Conflict | Strength and sustainability of opposition |
| Information gap | Curiosity generated by unequal/hidden knowledge |
| Reversal potential | Capacity for meaningful turns |
| Cliffhanger potential | Ability to create strong episode endings |
| Character potential | Depth and conflict available from the cast |
| Serial potential | Ability to sustain the requested episode count |
| Originality | Distance from generic/repetitive generation |
| Production feasibility | Practicality for eventual AI production |
| Continuity risk | Likelihood of contradictions or unmanageable complexity |

## 7. Episode Quality Gate

Before an episode reaches media production, Xerama should be able to answer:

- Is the opening immediately interesting?
- What does the protagonist want in this episode?
- What prevents that goal?
- What changes during the episode?
- What new information is learned?
- Does the episode advance the larger arc?
- Is there meaningful escalation?
- Is the ending unresolved for a valid dramatic reason?
- Is the cliffhanger different from recent cliffhangers?
- Does the episode contradict canon?
- Is the episode feasible to produce?

## 8. Principle

The system should optimize for continuation without sacrificing coherent payoff. Cliffhangers create the next click; accumulated promises and satisfying reversals create the series.
