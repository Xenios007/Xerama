# MODULE-026 — Character Visual Identity

**Status:** BUILD
**Depends on:** 013,040

## Objective
Turn narrative characters into persistent reusable synthetic performers.

## Requirements
- Root identity asset, structured Character DNA, multi-view references, expression references, wardrobe/physical-state variants and voice link.
- Lock/recast/version semantics.
- Identity assets must have provenance/rights metadata.
- Never mutate canonical identity to match a bad generation.

## Verification
Identity package persistence, lock/recast and variant tests.

## Done when
Recurring characters have stable visual identities independent of individual shots/providers; commit/push.
