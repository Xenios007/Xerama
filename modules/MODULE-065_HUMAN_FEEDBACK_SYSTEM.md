# MODULE-065 — Human Feedback System

**Status:** BUILD
**Depends on:** 060,063

## Objective
Capture operator preferences and review outcomes as structured learning signals.

## Requirements
- Record approve/reject/retake/edit reasons and optional ratings/tags.
- Link feedback to exact artifact/take/version/model.
- Separate subjective preference from objective QC failures.
- Provide export/query for later evaluation.

## Verification
Feedback persistence, lineage and aggregation tests.

## Done when
Human decisions become reusable evaluation data rather than disappearing in chat/logs; commit/push.
