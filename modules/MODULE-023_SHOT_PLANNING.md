# MODULE-023 — Shot Planning

**Status:** EXTEND
**Depends on:** 021,022

## Objective
Create complete production-oriented shot contracts.

## Requirements
- Include duration, characters, dialogue/action, shot size, angle, lens, movement, composition, lighting, emotion, narrative function and optional micro_beats.
- Mark dialogue coverage and continuity groups.
- Enforce runtime budget and mobile readability.
- Persist versions and shot ordering.

## Verification
Coverage, duration-budget, micro-beat and serialization tests.

## Done when
Every script can become a provider-neutral ordered shot list suitable for image/video generation; commit/push.
