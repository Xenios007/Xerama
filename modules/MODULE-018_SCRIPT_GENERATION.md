# MODULE-018 — Script Generation

**Status:** EXTEND
**Depends on:** 017

## Objective
Convert approved episode plans into concise vertical-microdrama scripts.

## Requirements
- Generate all episodes, not Episode 1 only.
- Use bounded canon/knowledge context.
- Keep dialogue compact and production-feasible.
- Persist scenes, dialogue, action and proposed canon changes.
- Support regenerate/rewrite per episode/scene.

## Verification
Multi-episode script generation, context isolation, persistence and retry tests.

## Done when
The full season can reach script-ready state without manual copy/paste; commit/push.
