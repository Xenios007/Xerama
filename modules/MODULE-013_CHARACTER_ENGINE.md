# MODULE-013 — Character Engine

**Status:** AUDIT/EXTEND
**Depends on:** 012

## Objective
Create canonical dramatic characters and long-term arcs before visual casting.

## Requirements
- Persist identity, role, goals, flaws, fear, desire, secrets, arc, relationships and knowledge state.
- Separate narrative character from later visual/voice assets.
- Support recurring/supporting/minor roles and active/inactive/dead states.
- Validate unique IDs and relationship references.

## Verification
Character creation, relationship graph and state-transition tests.

## Done when
Episode generation can query reliable character truth independently of prompts; commit/push.
