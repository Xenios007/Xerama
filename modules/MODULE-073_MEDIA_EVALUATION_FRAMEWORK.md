# MODULE-073 — Media Evaluation Framework

**Status:** BUILD
**Depends on:** 029,032,044,049,065

## Objective
Benchmark image/video providers by shot class and accepted-output economics.

## Requirements
- Curated test shots covering identity, dialogue, motion, establishing and multi-character cases.
- Record QC, human preference, retries, latency and cost.
- Compare reference strategies and provider capabilities.
- Keep live paid runs explicit/opt-in.

## Verification
Harness/data-schema tests with fixture outputs.

## Done when
Provider routing can be informed by repeatable media benchmarks; commit/push.
